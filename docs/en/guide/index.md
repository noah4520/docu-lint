# Guide

Good documentation lowers the cost of trying a project.

docu-lint helps you answer four questions:

1. Can I understand what the project does in three seconds?
2. Can I install it with one command?
3. Can I copy an example and see the result?
4. Does the writing feel consistent enough to trust?

## Try It

```bash
npm run demo
```

Then go through each issue and connect it back to the README structure:

- Title and tagline
- Quick start and installation
- Usage and API
- Contributing and license
